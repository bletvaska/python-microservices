# Lab: Stranka s pocasim

Vytvorte funkciu typu _path operation_ s názvom `homepage()`. Vlastnosti tejto funkcie budú nasledovné:

* cesta pre zobrazenie stránky bude `/`
* názov šablóny je `homepage.html`
* použitá HTTP metóda je `GET`

Jednotlivé premenné, ktoré je potrebné do šablóny dostať, spolu s ich významom, je nasledovný:

* `refresh` - časový interval obnovenia stránky
* `background_nr` - číslo obrázka pozadia
* `now` - aktuálny čas (nie čas merania)
* `weather` - objekt merania
